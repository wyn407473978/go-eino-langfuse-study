### D10 最后一项：退出前导出对照尚未开始

已布置任务，但 `cmd/export-lab/main.go` 尚未创建，也没有执行结果。

实验设计：

1. 独立短命令，只创建一个测试 trace，使用现有 Langfuse 回调依赖，不需要调用模型。
2. 沿用现有 Langfuse 地址和项目 Key；确认已恢复正确密钥。
3. 配置 `BatchTimeout: 30 * time.Second`、`MaxExportBatchSize: 128`。
4. 使用标准库 `flag.Bool("wait-export", true, ...)` 和 `flag.Parse()`，通过 `*waitExport` 获取开关值。
5. trace 名为 `export-lab`，输入标记模式，调用 EndTrace 设置输出。
6. true 模式：使用新建的 Background 派生 10 秒 context 调用 Shutdown，检查错误。
7. false 模式：EndTrace 后自然退出，不注册会执行 Shutdown 的无条件 defer。
8. handler 创建完成到进程退出明显短于 30 秒，以减少定时导出对实验的干扰。

计划运行命令：

```bash
go run ./cmd/export-lab -wait-export=false
go run ./cmd/export-lab -wait-export=true
```

要理解：EndTrace 结束观测；Flush 等待已完成数据导出但继续使用 handler；Shutdown 完成导出并关闭。未等待模式可能丢失记录，实际观察与错误日志才是验收证据。
